What's changed

Changes to analytics.lic and its dashboard, newest first. Each says whether it's the script (update the script to get it) or the dashboard (live on this site as soon as it's out), and anything you need to do.

1.0.0 · the first release

Not released yet: this entry is the draft for the day it ships.

  • Script analytics.lic records each character's hunts, rests, deaths and idle time, kills, silver (bank balances, sales, boxes, coins off the floor, bounty rewards, and what you spend), bounties and every task offered, shop stops, and where each character stands (level, experience, ascension, training points, Death's Sting, Lumnis and your resources). It never sends a game command beyond one quiet BANK ACCOUNT per character.
  • Script Text reports in the game window, alerts in the game and on Discord, and a daily digest.
  • Script Settings in two files: one for every character with the defaults, and one per character for overrides. See Settings.
  • Dashboard This site: an overview of every character, a page per character (Summary, Income, Hunting, Bounties, Progress, History) and Compare, reading your database in your browser.
  • Dashboard Alerts you can dismiss for the day, and choose which show and when. See Alerts on the dashboard.

What to do

  • Have your rest script type EXPERIENCE and RESOURCE once a rest, so fame, Death's Sting, training points and your resources are recorded. See First run.
  • If you tested an earlier build, move its analytics.db aside: the script refuses a database from another build and starts a fresh one. Delete your character's old analytics.yaml too, to get the new blank one.
