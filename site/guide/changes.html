What's changed

Changes to analytics.lic and its dashboard, newest first. Each says whether it's the script (update the script to get it) or the dashboard (live on this site as soon as it's out), and anything you need to do.

November 12, 2026 · dashboard and guide

  • Dashboard A Privacy section in the guide: what the script keeps on your computer, that Discord alerts (if you turn them on) are all it sends anywhere, what your browser keeps for this site, and how to delete it all. Every page's footer links it.
  • Dashboard The footer says what was always true: this is a fan-made tool, not affiliated with Simutronics. This site's code is now BSD 3-Clause licensed, as Lich is.

November 12, 2026 · dashboard, from the second audit

  • Dashboard Silver and experience per hour on a character's Summary now divide by the hours the script ran in the range (hunting, resting and idle), as the overview's cards always did and the guide says. They divided by every hour since the range began, logged out or not, so Today on a character's page could be an eighth of the figure on its card. Both now count a hunt or rest still going up to now, and show -- under ten minutes of play.
  • Dashboard Crashes today counts a hunt, rest or idle stretch that Lich or the connection cut off, which the script marks when it next starts (from this update of the script). It had only counted idle recoveries since hand stops stopped counting as crashes.
  • Dashboard The overview no longer redraws several times a minute with nothing new: the "Idle for", "No kills for" and "Bounty running" minutes all turn over on the minute, so a hover or the keyboard's place isn't lost between them.
  • Dashboard Show and Show all, for hidden characters, leave the keyboard on the character shown again instead of at the top of the page.
  • Dashboard On the day clocks go back, Last 24 Hours no longer draws the repeated hour twice.
  • Dashboard The warning for a database from another time zone says kills can land a whole day off, not just near midnight. A copy from the script that won't open says so, rather than calling it the wrong file, and the mind-capacity note shows only when it's missing.
  • Dashboard A database opened as a file can no longer put markup of its own into the Resources tiles.

November 12, 2026 · dashboard

  • Dashboard On a phone, the range tabs (Today to All Time) scroll sideways: All Time ran off the edge of the screen and couldn't be tapped. Tabs, a character's page links and wide tables now fade at the side that has more to scroll to.
  • Dashboard The Activity today chart fits each name on a phone, and keeps the game when a long name is cut, so two characters of one name stay apart.
  • Dashboard A link to a character the database doesn't have names it as you'd write it (Splinter (GS4)), and a page that couldn't be read says so rather than that nothing was recorded.
  • Dashboard A wrong address on this site gets a page with links back, not a blank one. A link to the guide or this page shows a preview when you share it, and the site's preview image no longer has the menu's buttons over its character list.
  • Script Dashboard Reporting a problem or asking for something new starts from a form on GitHub: a script bug, a dashboard bug, wrong or missing figures, a feature request, or the guide. Each asks for what's needed to act on it (versions, the game text, your browser). See the FAQ.
  • Dashboard On a short window, the menu scrolls rather than its buttons at the bottom covering the last characters in the list.

  • Dashboard The locksmith pool, on each character's Income page: how many of its boxes the pool holds, how that changed over the range, the peak, and how many boxes a full pool turned away, by town. On Compare, every character side by side.

A wide table is saved whole, every column included. Save image in the menu still saves the whole view.

1.0.0 · the first release

Not released yet: this entry is the draft for the day it ships.

  • Script analytics.lic records each character's hunts, rests, deaths and idle time, kills, silver (bank balances, sales, boxes, coins off the floor, bounty rewards, and what you spend, shop purchases included), bounties and every task offered, shop stops, and where each character stands (level, experience, ascension, training points, Death's Sting, Lumnis and your resources). It sends no game command of its own beyond one quiet BANK ACCOUNT per character, unless you turn on max_hunt_minutes, weapon_loadout or idle_recover_minutes, which act for you (see Settings).
  • Script Text reports in the game window, alerts in the game and on Discord, and a daily digest.
  • Script Settings in two files: one for every character with the defaults, and one per character for overrides. See Settings.
  • Dashboard This site: an overview of every character, a page per character (Summary, Income, Hunting, Bounties, Progress, History) and Compare, reading your database in your browser.
  • Dashboard Alerts you can dismiss for the day, and choose which show and when. See Alerts on the dashboard.
  • Script Dashboard Combat: the damage each character deals and the kills it is credited with, per kind of creature, read by Lich's own combat tracker. Kills, assists, damage per creature, per kill and per hit, and per hour hunting, on each character's Hunting page, and every character side by side, with the party's total, on Compare. Turn it off with the combat setting. See Combat.
  • Script Dashboard The locksmith pool: how many of each character's boxes it holds, from the list the worker gives when eloot asks for returns, and each box a full pool turns away. On each character's Income page, and side by side on Compare.

What to do

  • Have your rest script type EXPERIENCE and RESOURCE once a rest, so fame, Death's Sting, training points and your resources are recorded. See First run.
  • If you tested an earlier build, move its analytics.db aside: the script refuses a database from another build and starts a fresh one. Delete your character's old analytics.yaml too, to get the new blank one.
  • Test builds before this one counted the silver of creatures that melt or crumble when searched twice, once as the corpse's silver and again as coins off the floor, and could lose fame and Death's Sting readings when EXPERIENCE and RESOURCE were typed together. A database from those builds keeps the extra floor silver, so start a fresh one for true silver figures.
  • This build's database is schema 11 (it adds combat and the locksmith pool): one from an earlier test build is refused, so move it aside for a fresh one.
  • Test builds left a hunt open when the game connection dropped: the dashboard showed the character still hunting for two hours after it logged back in, and the hunt was later closed with the offline time counted as hunting. From this build, logging back in closes it when the login was last seen.
  • The first schema 11 test build counted every locksmith pool list as 0 boxes: the worker puts a blank line before each box, and the list was read as ending there. From this build the boxes are counted. The zero counts an older database holds stay: before starting this build, either start a fresh database or, with the script stopped, clear them with sqlite3 analytics.db "DELETE FROM pool_depth WHERE full = 0" (the boxes turned away were counted right and stay).
  • Test builds also split one rest into two when bigshot started and at once went back to resting (still poisoned or encumbered): a hunt too short to keep, between two rests. Rests were overcounted, by about an eighth in one tester's day, and each looked shorter. From this build the rest carries on through it.
  • Test builds read what other players said or whispered as if it were your own game text: anyone saying a line like a box's coins or a bank deposit had it recorded as your silver, and the same for kills, bounty rewards and task offers. This build skips speech and whispers, and ESP as the game is known to mark it (no tester's log had ESP in it yet, so if a thought on ESP ever shows up in your figures, tell us). If a test build's figures ever jumped for no reason, start a fresh analytics.db.
  • Also fixed in this build, from test builds: a death that went past midnight counted as two, and a rest's item-limit alert was sent again at midnight; a setting of the wrong kind (8m where minutes go) stopped hunts and rests being tracked, and is now reported and left out; max_hunt_minutes could ask for a rest again at once after a rest of a few seconds; and the weapon_loadout check could drop an item that wouldn't stow, which it never does now.
  • Test builds also missed some towns' wording: Cold River's, Mist Harbor's and Kraken's Fall's notes and chits for big sales, Mist Harbor's bank, the Icemule and Cold River locksmiths and the Kraken's Fall and Icemule locksmith pools. Those sales and fees are recorded from this build on, not in an older database.
  • Test builds read the Order of Voln's channel as your own game text, as they did speech before: a Symbol of Thought from any member saying a deposit or a box's coins had it recorded for every Voln member listening. This build skips it. It also no longer stops when a settings group is given one value (alerts: false): that's reported and left out, and each setting under it turns off on its own line. Two characters starting at once on a new database both open it, a session that finds the dashboard's port taken by another character's says the dashboard is already fed, and a shop's town comes from the map's fixed paths, so Sablecross's bank is in Sablecross whatever guides are about, and an outpost such as Khazar's Hold is named for itself.
  • From this build, a hunt, rest or idle stretch that Lich or the connection cut off is marked "crashed" when the script next starts, and when it ends where the next one began it keeps the experience it gained. Test builds left it unmarked, so the dashboard didn't count it as a crash, and its experience counted on the Summary but not on the overview.
